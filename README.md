## Capstone project: Loan Insights

For the final project of my Google Cloud Data Analytics course, I collected raw loan data, processed and stored it in BigQuery, and built a Looker Enterprise dashboard with:

- a single value tile for total outstanding loans
- a pie chart of outstanding loans by loan status
- a bar chart of outstanding loan counts by state
- a table of the top 10 customers by annual income

What it showed: 87.89% of outstanding loans were current, 9.07% had been charged off, and California had the most outstanding loans of any state.
